# Bearing Housing Blocks — Delivery Package

## Contents
- `freecad_macros/CSM_V3_BearingHousings_V1.FCMacro` — FreeCAD macro (both blocks)
- `blueprints/CSM_V3_BearingHousings_V1_VisualDiagram.svg` — Visual blueprint

## Usage
1. Open FreeCAD
2. Macro → Macros... → Add existing → point to the FCMacro file
3. Run the macro
4. STL, PNG, SVG, and chart will auto-export to:
   - `C:\3D-Project\01_MECHANICAL\05_BEARINGS_SHAFT\` (STL root)
   - `C:\3D-Project\01_MECHANICAL\05_BEARINGS_SHAFT\images\` (PNGs)
   - `C:\3D-Project\01_MECHANICAL\05_BEARINGS_SHAFT\blueprints\` (SVG)

## Parts produced
- TOP block: 60×60×20mm, 1× 6001-2RS
- BOTTOM block: 70×70×30mm, 2× 6001-2RS + 1× 51101 thrust
