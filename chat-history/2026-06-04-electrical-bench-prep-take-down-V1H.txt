TAKE-DOWN HOOK DESIGN HISTORY (TODAY)
================================================================

V1.0F (existing, generated 2026-05-27):
   - Multi-hook ring with cylindrical PETG hook stems D2.2 x 10 mm
   - 4-hook ring, 2-arm spider, central cord eye
   - Bug discovered: eye_post (D13 cylinder) started at Z=RING_T (6.5 mm)
     in print frame, floating over open ring ID with NO support below
   - First-layer of post would be Ø13 disc in mid-air; arms too were
     bridges with only one end anchored
   - Slicer would need supports across the ring interior bore

V1.0G (committed 70f7ea5):
   - Eye post extended from Z=0 (bed) to Z=19.5 (full height)
   - Post is now self-supporting column; arms bridge from ring inner
     wall (one end) to fully-supported post (other end)
   - 23 mm bridge span (well within PETG capability)
   - Volume +863 mm^3 = 20.3 g PETG (was 19.2 g in V1.0F)
   - V1.0F archived

V1.0H (committed 37b59de):
   User reported: V1.0F/G hook stems broke under light handling.
   Root cause analysis:
   - D2.2 x 10 mm vertical PETG cantilever
   - Layer lines horizontal across stem (weakest direction for bend)
   - Tiny "blend" sphere at root (r=1.1) -- no real fillet
   - Sphere-on-cylinder transitions at tip = additional stress riser
   - Theoretical clean break ~4 N (~400 g)
   - Practical layer-adhesion derate ~0.5: ~2 N (~200 g)

   V1.0H fixes:
   - HOOK_THICKNESS  2.2 -> 3.0 mm    (d^3 scaling: 2.54x stronger)
   - HOOK_DEPTH      10 -> 8 mm       (linear: 1.25x stronger)
   - BASE_BLEND_R    r_stem -> 2.0    (proper fillet at the root)
   - HOOK_BARB_OFFSET 1.8 unchanged
   - Theoretical clean break: ~13 N (~1.3 kg)
   - Practical: ~6.5 N (~650 g) -- 3.2x stronger overall
   - Mass: 20.4 g PETG (negligible change)
   - V1.0G archived

V2.0 (committed fa674f6, then rolled back 7bf6977):
   User pushed back: "Hook stems break by touch" suggests V1.0H still
   inadequate -> proposed wire-hook carrier architecture (steel wire
   inserts through ring; user bends J-hooks).

   V2.0 designed:
   - No printed hooks; only ring + spider + eye-post
   - 4 vertical through-holes D1.2 mm for steel wire (paperclip /
     music wire / fishing hook shank)
   - User bends wire after insertion
   - Field-replaceable in 10 seconds
   - Print has NO thin features

   THEN ENGINEERING PUSHBACK (correct):
   - "A properly printed 3 mm PETG cantilever should feel noticeably
     flexible BEFORE failure, not snap"
   - Most "breaks by touch" failures = print quality, not design:
     wet filament, low nozzle temp (<235), over-cooling, only 2 walls,
     Z-seam through stem root, mechanical damage on bed removal
   - Therefore V2.0 was premature architectural pivot

   Rollback (commit 7bf6977):
   - V1.0H restored from archive as current candidate
   - V2.0 macro + STL kept in live folder as architectural alternative
   - ICD R6: take-down row rewritten -- V1.0H "current candidate",
     V2.0 "alternative pending failure-mode diagnosis"
   - Phase 1 Guide V2.0 references reverted to V1.0H
   - NEW: §3.5 Failure Mode Diagnostic section added to Phase 1 Guide:
     * Required photo of fracture
     * Print parameter capture (filament, temp, walls, cooling, Z-seam)
     * Fracture location categorization (root / mid / tip)
     * Bed-removal method check ("broke during removal" != design fail)
     * Decision flow: print fix vs geometry fix (V1.0J conical fillet,
       drafted in guide not written) vs architecture fix (V2.0 ready)

User next step: print V1.0H with corrected settings (3+ walls, 240-250C
nozzle, dry filament, <50% cooling, random Z-seam). NO model changes
needed -- V1.0H STL already has D3.0 hooks. Then if it still breaks,
photograph fracture face and we diagnose properly.

OUTSOURCED PARTS DECISION
================================================================

User has 230x230 printer bed nominal / 220x220 reliable working area
(typical first-layer adhesion margin issue at corners).

Two largest parts in project:
   Cassette Base V1.1 -- OD 200 mm, complex disc with multiple PCDs
   Retainer Ring V1.0 -- OD 200 mm, thin annulus

Both fit on bed but with only 10 mm corner margin. For structural
datum-defining rings, that's bed-marginal. User chose to outsource
both as single-piece SLS PA12 from online service (not split/glue).

Phase 1 Guide §1.5 added:
   - STL upload paths
   - Spec: PA12 nylon SLS/MJF, standard finish
   - Cost: $15-25 retainer, $30-50 cassette base, ~$45-75 combined
   - Lead time 5-10 business days
   - Post-receipt inspection table (OD, PCDs, flatness, threads)
   - Rationale: these are datum-defining components, glued split-seam
     would be at exactly the wrong place

KEY ARCHITECTURAL DECISIONS THIS SESSION
================================================================

1. Take-down: V1.0H is the candidate; V2.0 wire-hook architecture is
   the fallback. Decide based on PHYSICAL diagnosis, not assumption.

2. Cassette base + retainer ring: OUTSOURCED, not split-and-bonded.
   These are datum-defining components; glued seams at exactly the
   wrong place.

3. Controller stack: Mega 2560 + Raspberry Pi 4 (NOT ESP32) per BOM.
   Mega handles real-time motor/servo; Pi handles UI + pattern logic.
   Link via UART/USB at 115200 baud.

4. PSU placement: LEFT zone of wood base, long axis along Y, terminals
   facing BACK strip. Deck-mounted terminal guard (Part F V0.9 ready,
   awaiting measurements).

5. Pi 4 + touchscreen: lives on touchscreen mast (ICD I10), not on
   wood base. Saves wood-base real estate.

6. Operator panel: vertical 200x60x3 mm at front edge, L-bracketed.
   Houses IEC C14 inlet, fuse, E-stop mushroom, status LEDs.

7. Two SEPARATE LM2596 5V bucks: one for Mega+servos, one for Pi.
   Sharing one buck makes servo transients crash the Pi.

8. Methodology: STOP iterating CAD on speculation; design around real
   measurements; use wait windows for non-CAD planning work
   (wiring/protocol/procedures/checklists).
