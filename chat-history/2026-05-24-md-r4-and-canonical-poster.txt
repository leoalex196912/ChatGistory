A. MACHINE_DATUMS R4 -- BELT GEOMETRY FIX
================================================================

ROOT CAUSE OF R3 BUG
--------------------
R3 had:
    MOTOR_X = 90.0,  MOTOR_Y = -100.0,  BELT_CENTER_DISTANCE = 134.5

That distance (sqrt(8100 + 10000) = 134.54 mm) is geometrically
impossible for the purchased belt:
    HTD 5M, 405 mm pitch length, 60T + 20T pulleys.

Belt-length equation:
    Lp = 2*C + pi*(D1+D2)/2 + (D1-D2)^2/(4*C)

With:
    D1 = 60*5/pi = 95.493 mm    (60T pitch diameter)
    D2 = 20*5/pi = 31.831 mm    (20T pitch diameter)
    Lp = 405 mm

Solving:
    8*C^2 - 4*k*C + (D1-D2)^2 = 0     where k = Lp - pi*(D1+D2)/2 = 205
    discriminant = k^2 - 2*(D1-D2)^2 = 33919.31
    C = (k + sqrt(disc)) / 4 = 97.293 mm    (real solution)
    C =  5.207 mm                            (degenerate, ignore)

So the only valid center distance is C = 97.29 mm.
